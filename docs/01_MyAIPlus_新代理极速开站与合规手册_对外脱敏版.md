### 第 2 步：购买独立短域名（切忌使用二级长前缀子域名）
- **为什么一定要买独立短域名？** AI 工具用户普遍熟悉网络操作，如果使用免费长前缀子域名，客户容易截断前缀访问主站。自己花十几元注册一个 **4～8 位好记的短域名**（推荐 `.store` / `.shop` / `.xin` / `.com`），品牌独立感强，也方便小红书/微信口头报网址。
- **购买渠道**：阿里云万网（首年约 ¥14）或腾讯云助手小程序（首年优惠约 ¥1～¥14）；下单时记得**关闭自动续费**，不要勾选网盘、SSL 证书、AI 建站等附加收费项。

### 第 3 步：NS 一键绑定域名（自动 HTTPS 免备案）
1. 登录你的分站后台 → 左侧菜单 **`我的店铺`** → **`域名绑定`** → **`添加独立域名`**；
2. 接入方式选择 **「NS 接入（Cloudflare 加速）」**，填写你买的根域名（例如 `yourdomain.store`，**不要加 `https://` 或 `www.`**）后提交；
3. 复制后台分配给你的 2 条专属 `*.ns.cloudflare.com` DNS 地址；
4. 前往域名注册商控制台（阿里云：`管理 → DNS 修改`；腾讯云：`修改 DNS`），删除默认 DNS 记录，替换为这 2 条 `*.ns.cloudflare.com` 地址并保存；
5. 等待几十分钟到几小时（最长 24～48 小时），系统会自动完成 **根域名 + www 接入 → 源站解析 → 访问加速 → 自动签发 HTTPS 证书**（免国内服务器备案，省去繁琐手续）。

### 第 4 步：店铺装修、公告与提现配置
1. **`我的店铺 → 店铺设置`**：
   - 设置好清晰的 **店铺名称**、**网站标题** 和 **SEO 关键词/描述**；
   - **上传专属正方形品牌头像**（替换默认头像，强化独立小店品牌感）；
   - 填写 **店铺公告**：写明「24 小时自动发货」「页面顶部『我的订单』自助提货」「你的售后联系方式/微信」以及「招下级代理入口」；
   - 保持 `显示主站商品[全局]`、`显示会员等级价格`、`显示在线客服` 三个开关处于开启状态；
   - **⚠️ 记得隐藏测试类目/测试商品**：进入 `管理商品`，把测试分类及测试商品设为 `隐藏`。
2. **`安全中心 → 个人资料`**：填妥 **真实姓名（提现用）、支付宝账号、支付宝收款码**，佣金满 **¥10** 即可随时申请提现。

### 2. 后台调价 4 个实战细节（新人必看）
